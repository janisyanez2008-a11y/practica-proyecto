 Product backlong-Registro de alumnos y calificaciones 
 
 Epica 1-Registro de alumnos y calificacion
 US2:como usuario, quiero registrar un alumno con nombre, grupo y cinco calificaciones, para llevar un control academico.
 US3:como usuario, quiero que el sistema valide que todos los campos estén llenos y las calificaciones sean números validos, para evitar errores de captura

 Épica 2-Consulta de alumnos
 US4:Como usuario, quiero ver la todos los productos en un DatoGridView para tener una visión general del inventario.
 US5:como usuario, quiero buscar productos por nombre o código, para encontrarlos rapidamente.

 Épica 3-Modificacion de productos
 US6:como usuario, quiero modificar los datos de un producto ya registrado, para mantener la información actualizada.

 Épica 4-Eliminacion de productos
 US7:Como usuario, quiero eliminar un producto con confirmación previa, para no borrar la información por error.

 Épica 5-control de stock (mejora opcional)
 US8:como usuario, quiero recibir aviso cuando la cantidad de un producto sea menor a 5, para saber que debo debastecerlo.
 US9:como usuario, quiero ver un listado de productos con stock bajo, para compartir el inventario con otros.

 Epica 6-reportes y presentacion (opcional si hay tiempo)
 US10:como usuario, quiero ver el valor total del inventario (cantidad x precio de cada producto), para conocer la inversión total.
 US11:como usuario, quiero exportar el listado a un archivo de texto o exel, para compartir el inventario con otros.
